## 三、快速使用指南

### 1. 教室大螢幕帶練／手機平板與在家自主練習（V4.04 超簡單 3 步驟）
- 確認 `Try_Everything_五年級運動會進場舞_互動帶練系統.html` 與 `Try_Everything_鏡面教學原片.mp4` 放在同一個資料夾內，直接雙擊 `.html`（或透過網站 `index.html`）即可使用。
- **教室投影／手機直拿小撇步**：需要遠看時點頂部 **`🔍 放大影片／手機平板大字模式`** 即可一鍵放大；手機或放大模式下想連貫練前後招式，直接按播放列的 **`⏮ 上一動`**／**`下一動 ⏭`**（電腦可用方向鍵 `←` `→`），不用往下捲找圖！
- 練習流程：
  1. **看圖擺姿勢**：點選上方第 1～8 段任一按鈕，先看右側真人照片與精簡大字 **`🎯 動作 ／ 💡 提醒`**，原地擺出動作。
  2. **慢速跟跳整段**：點擊左下方預設的 **`🚶 第二步：慢速連跳這段 ①➔④ (0.75x)`**，真人影片會慢速循環帶跳，右邊圖片會跟著亮金框；**哪一格跟不上，直接點那張照片**就會改成 0.6 倍慢速單獨重播（依實際音樂拍點精準剪輯並在結尾短暫定格 0.35 秒，看清收尾動作再重播！）。
  3. **原速過關進下一段**：練熟後點擊 **`🏃 第三步：原速過關挑戰`**，完整跳完本段自動暫停並給予過關鼓勵，點「前往下一段」繼續闖關。全部練完後可點右上角 **`🏆 全曲連跳`** 總驗收。
- 需要紙本口訣表時，直接點選網頁最底部的 **「📄 A4 八拍口訣與自練檢核單」** 即可開啟列印。

### 2. 列印紙本口訣小抄與教師評量表
- 雙擊開啟 `04_學習單與評量/Try_Everything_運動會進場舞_八拍口訣與自練檢核單.html`。
- 上方工具列可一鍵切換「📄 學生發放版」、「👩‍🏫 教師備課與評量規準版」或「📑 雙面全印」，點擊「🖨️ 一鍵列印 A4 橫式」即可滿版印出。
